v3.0.7: Your Characters Everywhere in Create, and More of Create on the Mac

Locally Uncensored 3.0.7 came out on [TO CONFIRM: release date, e.g. October 16, 2026]. A character you trained now works on every tab of Create, not only on Image, and it brings the model it was trained for. Character cards from role play apps import as personas. Create gets a local Enhance Image, folders in the gallery and the settings of every result. On a Mac, Create gains six tools it did not have in 3.0.6.

Many of the requests in this release came from the Discord and from GitHub issues. We list what we have not tested at the end of this post.

The short version:

  • Characters everywhere in Create: a character chip on Image, Edit and every video tab. A video starts from a picture of the character
  • Character cards: import a PNG or JSON card as a persona, with its picture and its greeting
  • Enhance Image runs locally on Windows and Linux, 2x or 4x
  • Gallery folders and the full settings of a result next to its prompt
  • Think budget for the bundled engine
  • More of Create on the Mac (Beta): Edit with a mask, HiRes, Remove Background, Enhance, Extend Video and Music
  • Fixes for ComfyUI on a machine with Python 3.15, for GPU layers on AMD and Intel cards, and for the microphone on Linux

Your Character on Every Tab of Create

In 3.0.6 a character you trained in Character Studio worked on Image. In 3.0.7 a character chip sits next to the model chip on Image, Edit and every video tab. Picking a character sets an installed Z Image model, the model it was trained for. Where none is installed, the line under the character says so with a button to switch, and Create does not start a run that would leave the character out (issue 161).

On Image and Edit the trigger word goes into the run by itself. On Video, Animate, Extend, Multishot, MiniMax H3, Motion Control and Talking Character the run has two steps: LU first makes a picture of the character in the shape of the video, then starts the video from that picture. The progress reads Step 1 of 2 and Step 2 of 2, and Stop in step 1 ends both. A start image of your own wins over the character. A text only video model says why it cannot start from a character.

The line under the character also says to describe its key features in the prompt, because the trigger word alone often does not hold the look.

Three more ways in and out:

  • Frames from a video: the large view of a clip offers Use frames for a character. It takes 8 frames spread over the clip, 4 to 20 with the slider, and you untick the ones that do not show the figure. The frames go to Character Studio as a training set or are kept as a named character
  • A cloud character on your machine: Use locally on the LU Cloud shelf saves a Z Image character into the local LoRA folder, so Use character lists it. A file of the same name is never replaced
  • Delete a character: the local shelf has a delete button. It asks first and moves the file to the Recycle Bin or Trash

A chat model can ask for a character too: the image and video tools of the agent take one.

Character Cards for Role Play

A character card as PNG or JSON (versions 1, 2 and 3 of the common card format) imports as a persona, with the card picture as its tile. A new chat with that persona starts with the card's greeting as the first answer. Alternate greetings can be switched with arrows until you write. A card persona exports back as a JSON card.

Lorebooks are not read, and there is no setting for your own name in the card yet.

Create: Enhance, Folders and the Settings of a Result

  • Enhance Image is a local tab on Windows and Linux. It upscales 2x or 4x with Real-ESRGAN x4plus, a 67 MB model that LU downloads on request and checks by its SHA-256, on ComfyUI's own nodes
  • Gallery folders: a folder is a label in the app, the files stay where they are. Removing a folder keeps its pictures. While a folder is open, new results land in it
  • Prompt and settings: next to the prompt of a result the gallery shows the negative prompt, model, steps, CFG, sampler, seed and size, with one button that copies all of it. Only what took part in the run is listed
  • Animate offers Wan 2.1 VACE with your picture as the reference. Reference models it cannot run are listed with the reason instead of failing at the start
  • Clip length per video family: MiniMax H3 goes up to 362 frames, 15 seconds at 24 fps, and the slider steps on the grid each model uses, so it shows the length a run makes
  • Create reads the model lists again when you come back to the app, so a model you placed by hand shows up without a visit to Models

More of Create on the Mac (Beta)

The Mac build makes images and video without ComfyUI. 3.0.7 adds:

  • Edit with a mask, with strength and a soft edge
  • HiRes as a second pass over the picture, with a model that edits (Qwen-Image 2.1)
  • Remove Background through macOS Vision, with no model to download and no Python
  • Enhance Image with the SeedVR2 3B upscaler, a 7.28 GB download, 2x or 4x
  • Extend Video on the MLX video models that take a start image
  • Music with ACE-Step 1.5, from 10 seconds to 4 minutes
  • Characters from the Mac's LoRA folder, in Create and in the chat

Chat and Agent

  • Think budget: next to Think in the sampling pop-up and in Settings, Generation. 0 means auto, as before. The bundled engine takes a budget. Where a backend has none, the field is disabled and says so
  • Read aloud speaks what the answer shows. With a thinking model the voice also pronounced markers that stood nowhere on the screen. Read aloud and the automatic reading now take the cleaned text the bubble shows (issue 160)
  • Files the model cannot read: in a plain chat a binary file gets a clear line that the model cannot read it, with its type and size. In Agent and Code the file lands in the working folder and the model gets its name, type, size, SHA-256 and path, with the instruction not to run it unless you ask. The limit is 256 MB
  • Compaction keeps one state: a new pass merges the earlier summary with the new turns, and a check puts back requests, open items, paths and numbers the model dropped (issue 151)
  • Model ids a server does not list can be added per address on the provider card (issue 112)
  • The User-Agent of web search and page fetching can be set under Settings, Search Provider
  • The voice engine and LU's own Python can live on another drive. Settings, Model Storage has a row for them. Moving copies the files, checks the copy, starts it once and only then puts the old files in the Recycle Bin or Trash

Fixes Worth Knowing About

  • ComfyUI starts again on a machine whose only Python is one PyTorch does not serve yet, such as Python 3.15. Install and Repair build ComfyUI's environment from LU's own Python 3.12 then, without administrator rights
  • GPU layers -1 on an AMD or Intel card lets the engine fit the layers itself. On a Navi 10 card it ran as slow as the processor (issue 156)
  • On Linux, Voice and dictation get the microphone. The web view refused it before (issue 162)
  • Unloading a model no longer wakes the LM Studio service when its server is off
  • A model with an image part no longer tries a memory hand-off the engine cannot do

Security

ComfyUI and LM Studio, when LU starts them, answer to LU only, so other pages open in your browser can no longer read them. A page the agent fetches reaches the model marked as data, not as an instruction.

What We Have Not Tested

The changelog has the full list. These are the points we think you should know before you rely on something:

  • Characters ran on one Windows machine (RTX 3060, 12 GB) with a stand-in character file, not a character trained from real photos, so how closely the result keeps a face is not tested. On Image the character switches to Z-Image Turbo and its trigger word goes in; Edit without a mask works, with a mask you get a clear message. The video chain now refuses before the first step when no video model is installed. The second step, the clip itself, has not run on our test machine, which has no video model.
  • The longer clips of MiniMax H3 have not run on our test machine, which has no video model installed. They need a lot of graphics memory, and we have not measured how much
  • The microphone fix for Linux has been built and type checked for Linux, not run on a Linux machine with a microphone
  • GPU layers -1 has not been tried on a Navi 10 card, only on NVIDIA, where nothing changes
  • A cloud character used locally has not been tried with a real account in the installed app
  • Character cards ran with Holo and Qwen models. A Gemma model has not been tried
